# Code of Conduct

Kavrynt follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

It applies in every project space: issues, pull requests, discussions, chat,
and events, and when someone represents the project in public.

## Reporting

Report unacceptable behavior to the maintainers at
[support@kavrynt.com](mailto:support@kavrynt.com). Reports are handled confidentially. A
maintainer involved in a report takes no part in handling it.

The maintainers listed in [MAINTAINERS.md](MAINTAINERS.md) enforce this code
using the Contributor Covenant's enforcement guidelines.
